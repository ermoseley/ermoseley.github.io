About the simulation

This demo solves the isothermal Euler equations on a periodic grid using a first-order finite-volume scheme. You can switch between HLL and local Lax–Friedrichs fluxes. The timestep is set from the current wave speeds.

The histogram shows the distribution of log density. Supersonic turbulence produces large density contrasts; changing the forcing mixture changes the distribution. The reference curve uses a relation calibrated in three dimensions, so agreement in this two-dimensional box is qualitative.

Mass error and solver restarts are reported alongside the flow statistics. Reset starts a new realization.
